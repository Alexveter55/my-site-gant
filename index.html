❓ Краткая инструкция

Как пользоваться графиком монолитных ЖБ работ

📊 Назначение

Интерактивная диаграмма Ганта для планирования монолитных работ на месяц. Каждая строка — конструкция + этап + бригада. Каждая ячейка — день месяца.

🖱️ Работа с таблицей

  • Клик по ячейке — открывает редактор: количество рабочих, описание работ, примечание, цвет.
  • 0 рабочих — ячейка остаётся закрашенной и означает «запланировано без людей».
  • Число в ячейке — количество рабочих на этот день.
  • Строка «ИТОГО» внизу — сумма рабочих по каждому дню (с учётом фильтров).

✏️ Режим «Карандаш»

  • Нажмите кнопку «✏️ Карандаш» в панели инструментов.
  • Шаг 1: кликните по ячейке-образцу — с неё скопируются люди, описание, примечание и цвет.
  • Шаг 2: кликните по второй ячейке диапазона (в любой строке, любой день).
  • Система заполнит прямоугольный диапазон между образцом и конечной ячейкой копиями образца.
  • Если образец был пустой ячейкой, диапазон станет пустым — удобно очищать блоки.
  • Для выхода нажмите «✖ Выйти» или клавишу Esc.

⚙️ Управление строками

  • ➕ Добавить строку — укажите конструкцию, этап и бригаду.
  • ⬆️ / ⬇️ — переместить строку выше или ниже.
  • ✏️ — переименовать; 🎨 — цвет строки; 🗑 — удалить.

🔎 Фильтры

Панель «Фильтры» позволяет отфильтровать строки по конструкции, этапу и бригаде. Итоги и экспорт учитывают фильтр.

📚 Справочник работ

  • Открывается кнопкой «📚 Справочник работ».
  • При переименовании работа автоматически обновляется во всех ячейках графика.
  • Новая работа, введённая вручную в ячейке, автоматически попадает в справочник.

📤 Экспорт

  • 📥 Excel (.xls) — два листа: «Гант» и «Детализация» с гиперссылками между ними.
  • 📄 CSV — плоская таблица + блок детализации.
  • 💾 / 📂 JSON — сохранение и загрузка полного проекта.

📅 Месяц и сохранение

  • Выбор месяца пересчитывает количество дней (28–31).
  • Все изменения сохраняются автоматически в браузере (localStorage).
  • 🔄 Сбросить данные — вернуть исходный график.
💡 Совет: если данные не отображаются, откройте консоль (F12) — там будет строка ✅ Init. Строк: N, Дней: M.
